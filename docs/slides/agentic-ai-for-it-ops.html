What is agentic AI?

From ask to hand off

Same underlying model. The difference is what it's allowed to do

Ask and answer

GenAI

You ask, it answers. One prompt, one response

Analogy Like asking a smart colleague a question across the desk

Goal and result

Agentic AI

You give it a goal. It plans the steps, uses tools, checks its own work and comes back with a result

Analogy Like handing a task to a colleague who does the legwork and returns a draft for you to review

Confidential and Proprietary8

GitHub and friends

Why GitHub in an AI session?

Nobody here needs to set up agents themselves

  • Agents work on files, and files change
  • Someone has to see what changed and undo it if it's wrong
  • Git is the standard safety net, for people and for agents
  • You don't need to become developers, you need to read the vocabulary
Confidential and Proprietary9

GitHub and friends

Git versus GitHub

One is the engine, the other is the platform around it

Runs on your machine

Git

Tracks every change to a folder of files

Analogy Track Changes plus version history, for a whole folder

Lives online

GitHub

Hosts Git projects with sharing, reviews and permissions

Analogy SharePoint with an approval workflow built in

Same idea

Similar tools

GitLab, Bitbucket and Azure DevOps do the same job

Analogy Different vendor, same vocabulary

Confidential and Proprietary14

Risks and guardrails

Common agent risks

RiskWhat it looks like for usGuardrail
Wrong action taken
Fixes the wrong device or recordAgents propose, humans act
Too much access
Reaches systems it never neededLeast privilege. Deny rules are a convention, not a boundary. PR review is the control
Confident errors
A plausible but invented fact in a planCheck sources, add a second reviewer
Prompt injection
Hidden instructions in a ticket, email or web page steer the agentTreat input as data, limit its actions
Sensitive data exposure
User data lands where it shouldn'tApproved tools only, minimal data
Silent changes, no trail
Nobody knows what it did or whyBranch, commit, review the diff in a PR
Over-trust over time
Reviews get rubber-stampedKeep the checkpoint real, rotate reviewers

Risks and guardrails

How our demo applies this

RiskHow the demo handles it
Wrong actionAgents only write a proposed plan. A human decides and acts
