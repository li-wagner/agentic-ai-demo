# Agentic AI Demo: New Hire Data Checker

A small demo for the IT Ops agentic AI training. It shows how an AI agent
(Claude Code) works through a task step by step, and where the human stays
in control.

> ⚠️ All data in this repository is fictional. Northwind Corp, its people and
> its rules are invented for training purposes. This is a personal sandbox,
> not a company system.

## What's inside

| File | Purpose |
|---|---|
| `CLAUDE.md` | The agent's runbook: the rules it must follow |
| `new_hires.csv` | 15 fictional new hires to check |
| `validate.py` | Created by the agent during the demo |
| `report.html` | Generated by the script, not stored in the repo |

## What the demo shows

1. **Plan first:** the agent proposes a plan before doing anything
2. **Ask before acting:** it asks permission before creating or running files
3. **Human decides:** a "no" stops the agent
4. **Changes via pull request:** fixes are proposed, a human reviews and merges
5. **Enforced guardrails:** `main` is protected, direct pushes are blocked

## Key takeaway

The agent does the work. The human owns the decision.
